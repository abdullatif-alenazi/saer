# إشعار البريد عند تسجيل عميل جديد

الآلية ترسل من خادم التطبيق عبر Resend، ويستدعيها مشغّل قاعدة بيانات Supabase عند إنشاء مستخدم جديد في `auth.users`. لا يُرسل مفتاح البريد إلى المتصفح.

## الإعداد مرة واحدة

1. في Resend، أنشئ مفتاح API وتحقق من نطاق المرسل. استخدم عنوانًا من النطاق الموثق في `SAER_SIGNUP_FROM_EMAIL`.
2. في إعدادات مشروع Vercel، أضف المتغيرات التالية لكل بيئة تريد تفعيل الإشعار فيها:
   - `RESEND_API_KEY`: مفتاح Resend.
   - `SAER_SIGNUP_NOTIFICATION_EMAIL`: البريد الذي تريد استقبال التنبيهات عليه.
   - `SAER_SIGNUP_FROM_EMAIL`: اسم وعنوان المرسل، مثل `Saer <notify@example.com>` بعد توثيق النطاق.
   - `SAER_SIGNUP_WEBHOOK_SECRET`: سر عشوائي قوي لا يقل عن 32 حرفًا.
3. في Supabase، فعّل إضافة قاعدة البيانات `pg_net`.
4. خزّن السر نفسه في Supabase Vault باسم `saer_signup_webhook_secret`، ثم شغّل ملف الترحيل `20261015_signup_email_notification.sql` مرة واحدة في SQL Editor.
5. أعد نشر Vercel بعد ضبط متغيراته، ثم اختبر التسجيل بعنوان جديد.

لا تضع مفاتيح Resend أو السر في ملفات المشروع أو ترسلها في المحادثة. لا يرسل التطبيق بيانات التسجيل القديمة بأثر رجعي؛ يبدأ التنبيه للتسجيلات الجديدة بعد تفعيل الإعدادات والمشغّل.
